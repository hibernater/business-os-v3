# Interruption Policy

只有以下情况允许中断用户并等待人工输入：

1. 缺少执行当前任务所必需的账号、密钥、权限或外部文件。
2. 任务存在关键产品方向冲突，继续推进会明显跑偏。
3. 需要进行破坏性操作，例如删除大量数据、重写历史或不可逆迁移。
4. 遇到安全、合规、法律或支付类高风险决策。
5. 本地环境或依赖问题导致无法继续推进，并且已经尝试常规修复仍无法解决。

以下情况**不应中断**：

- 命名、目录划分、轻量重构等小决策
- 文案优化、信息架构微调、页面结构微调
- 局部实现细节选择
- 为完成当前任务所需的小型辅助文件或 mock 数据调整

若命中允许中断的条件，需在中断信息中明确说明：

1. 当前任务 ID
2. 当前阻塞点
3. 已尝试的解决路径
4. 需要用户提供的最小输入
