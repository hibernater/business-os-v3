# Task Template

## Status
pending

## Objective
一句话说明本任务要完成什么。

## Background
- 与本任务相关的背景
- 相关 context / decisions / risks 文件引用

## Scope
1. 范围项 1
2. 范围项 2
3. 范围项 3

## Non-goals
- 不在本轮做的内容
- 防止任务蔓延

## Deliverables
- 要写入的 outputs 文件
- 可能涉及的代码或文档文件

## Acceptance Criteria
- 完成后如何判断任务达标
- 应包含可验证的交付结果

## Default Decisions
- 默认取舍规则
- 未命中 interruption policy 时的自主决策原则

## Interrupt Only If
1. 需要外部凭证 / 权限
2. 重大方向歧义无法自行收敛
3. 高风险 / 破坏性操作
4. 环境阻塞导致无法继续

## Next Task
- 下一个任务卡文件名；如果没有则写 `none`

## Completion Contract
任务完成后必须：
1. 将正式产出写入 `docs/outputs/`
2. 更新 `docs/status/STATE.md`
3. 更新 `docs/status/TODO.md`
4. 记录关键决策到 `docs/status/DECISIONS.md`
5. 如有风险或遗留项，更新 `docs/status/RISKS.md`
