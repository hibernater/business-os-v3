# Outputs

This directory stores durable outputs produced by the harness-driven workflow.

## Naming convention

- `001-product-definition-output.md`
- `002-prd-and-ia-output.md`
- `003-wireframes-output.md`
- `004-mvp-frontend-output.md`
- `005-runtime-schema-output.md`

## Output requirements

Each output file should include:

1. What was completed
2. Key decisions
3. Validation or evidence
4. Risks / limitations
5. Recommended next task

Outputs are part of the repo memory. Important work should be written here, not only described in chat.
