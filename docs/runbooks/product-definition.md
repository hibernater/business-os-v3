# Product Definition Runbook

## Goal
Produce a product-definition artifact that is specific, opinionated, and directly usable for design and engineering follow-up.

## Inputs
- `docs/context/product-vision.md`
- `docs/context/target-users.md`
- `docs/context/references.md`
- `docs/context/product-principles.md`
- Current task card

## Required Output Sections
1. Product one-liner
2. Priority user segment
3. Core pain points
4. MVP scenario selection
5. Core value proposition
6. Agent team design
7. Skill and workflow structure
8. IA and page list
9. Risks and open questions

## Decision Rules
- Choose one MVP wedge; do not hedge across many.
- Prefer business-result language over AI-jargon.
- Explicitly state non-goals.
- Tie agent roles to believable operating behavior.

## Completion Checklist
- Output saved to `docs/outputs/`
- `docs/status/DECISIONS.md` updated with key choices
- `docs/status/RISKS.md` updated with unresolved questions
- `docs/status/STATE.md` updated
