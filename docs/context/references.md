# Product References

## Reference 1: openclaw

关注点：
- skill 作为能力单元
- workflow 作为业务推进机制
- 自动执行和任务流转
- 系统不是单轮问答，而是能持续推进工作

可借鉴：
- 技能化能力组织
- 工作流编排
- 多步骤执行与状态流转
- 结果导向而非对话导向

不直接照搬：
- 不能让前台交互过于工程化
- 不能让用户像在看流程图后台
- 目标用户不是技术用户，而是老板

## Reference 2: ralv.ai

关注点：
- agent 拟人化
- UI 让用户感觉在安排一组角色工作
- 更强的陪伴感、掌控感、代入感

可借鉴：
- agent 的角色感
- 团队化呈现
- 工作状态可视化
- 更轻松、直观的指挥体验

不直接照搬：
- 不要太游戏化
- 不要削弱经营工具的可信度
- 不能只强调可爱和陪伴，而缺少业务结果
