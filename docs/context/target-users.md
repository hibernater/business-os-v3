# 目标用户画像

## 核心用户
- 中国制造业 / 产业带中小企业老板
- 老板娘、业务负责人、销售负责人
- 常见于：工厂、档口、批发商、外贸团队、小型品牌商家、供应链协同团队

## 共同特征
- 时间碎片化，不愿学习复杂软件
- 不关心 AI 技术原理，只关心是否能提升经营结果
- 更容易理解“员工 / 任务 / 结果 / 风险”，不容易理解复杂配置系统
- 往往同时承担销售、管理、决策和救火角色

## 高频痛点
- 客户线索和询盘多，但跟进不稳定，容易漏单
- 团队执行力波动大，很多事要靠老板亲自催
- 日常经营杂事多，老板很难持续看清重点
- 老客户复购和客户维护容易断档
- 缺少一个能持续推进工作的系统，而不是只是记录信息的系统

## 他们真正想买的不是 AI，而是：
- 更少漏单
- 更少自己盯人
- 更快知道什么事最值得优先处理
- 一套“像带数字员工团队一样”运转的经营系统

## 第一批用户建议
第一批更适合聚焦在：
- 外贸工厂老板
- 轻定制 / 订单驱动型制造老板
- 需要同时协调客户、交期、生产、利润和异常的经营者

原因：
- 业务链长，AI 团队式产品更容易体现价值
- 经营节点多，workflow / skill 更有用
- 老板对“持续推进”而不是“单次回答”的感知更强
